# คู่มือตั้งค่า Google Sheet กลาง (ให้ทุกมือถือ/แท็บเล็ตใช้ข้อมูลชุดเดียวกัน)

ตอนนี้ข้อมูลที่ลงในแอป **เก็บอยู่ในเครื่องที่ลงเท่านั้น** เครื่องอื่นจะไม่เห็น
ทำตามขั้นตอนนี้ครั้งเดียว (ประมาณ 10 นาที) แล้วทุกเครื่องจะส่งข้อมูลเข้า Google Sheet เดียวกัน และดึงของคนอื่นมาแสดงให้อัตโนมัติ

## 1. สร้าง Google Sheet
1. เข้า https://sheets.google.com ด้วยบัญชี Google ของโรงงาน (บัญชีนี้จะเป็นเจ้าของข้อมูล)
2. กด **ว่าง (Blank)** ตั้งชื่อ เช่น `โรงชิพ – ข้อมูลประจำวัน`

## 2. ใส่โค้ด
1. ในชีต กดเมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้งให้หมด
3. คัดลอกโค้ดทั้งหมดจากไฟล์ `Code.gs` (ที่แนบมากับแอป) ไปวาง แล้วกด **บันทึก** (รูปแผ่นดิสก์)
4. (แนะนำ) ตั้งรหัสลับกันคนนอก: แก้บรรทัด `var KEY = '';` เป็นเช่น `var KEY = 'chip2569';`

## 3. เปิดให้แอปเรียกใช้ได้ (Deploy)
1. กดปุ่ม **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดรูปเฟือง เลือก **เว็บแอป (Web app)**
3. ตั้งค่า
   - **ดำเนินการในฐานะ (Execute as):** ฉัน (บัญชีโรงงาน)
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** ทุกคน (Anyone)
4. กด **ทำให้ใช้งานได้** → Google จะถามสิทธิ์ ให้กด **อนุญาต** (ถ้าขึ้นว่า "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด *ขั้นสูง → ไปที่โปรเจกต์* เพราะเป็นโค้ดของเราเอง)
5. คัดลอก **URL ของเว็บแอป** ที่ลงท้ายด้วย `/exec`
   - ถ้าตั้งรหัสในข้อ 2.4 ให้ต่อท้ายลิงก์ด้วย `?key=รหัส` เช่น `https://script.google.com/macros/s/xxxx/exec?key=chip2569`

## 4. ใส่ลิงก์ในแอป (ทำทุกเครื่องที่ใช้ลงค่า)
1. เปิดแอป → **เพิ่มเติม → ตั้งค่า** → หัวข้อ **Google Sheet กลาง**
2. วางลิงก์ในช่อง **ลิงก์ Web App ของ Apps Script** แล้วกด **บันทึก**
3. กด **ส่ง/รับข้อมูลตอนนี้** — ถ้าสำเร็จจะขึ้น "ส่ง … · รับ … รายการ"

หลังจากนี้แอปจะส่ง/รับเองทุกครั้งที่กดบันทึก ตอนเปิดแอป ทุก 5 นาที และตอนกลับมามีอินเทอร์เน็ต
ถ้าไม่มีเน็ต ข้อมูลจะรอในเครื่องแล้วส่งให้ภายหลัง (จำนวน "รอส่ง" ดูได้ในหน้าตั้งค่า)

## 5. ในชีตจะมีอะไร
| แผ่นงาน | ใช้ทำอะไร |
|---|---|
| `entries`, `issues`, `settings` | ข้อมูลดิบที่แอปใช้ซิงก์ **ห้ามแก้หรือลบ** |
| `ไม้ยูคา`, `ไม้เชื้อเพลิง`, `สับขอบบอร์ด`, `มิเตอร์ไฟ`, `จักรกลหนัก`, `เวลาเดินเครื่อง` | สำเนาอ่านง่าย 1 แถวต่อวัน (หัวคอลัมน์เป็นชื่อช่องภาษาอังกฤษสั้น ๆ ของแอป) ใช้ดู/ทำกราฟต่อได้ |

> รายงานสรุปพร้อมต้นทุนต่อตันให้ดูในแอป หน้า **รายงาน** หรือกด **Excel ทั้งเดือน** เพื่อได้ไฟล์ที่จัดรูปแบบแล้ว

## ข้อควรรู้
- ถ้าสองคนแก้ข้อมูลวันเดียวกันแผนกเดียวกัน **ของที่บันทึกทีหลังจะเป็นตัวจริง**
- การ **ลบ** ข้อมูลในเครื่องหนึ่ง ยังไม่ถูกลบในชีต/เครื่องอื่น (ให้แก้เป็น 0 แทนการลบ)
- อัตราค่าไฟ ค่าแรง วันหยุด ที่แก้ในหน้าตั้งค่า จะส่งไปทุกเครื่องด้วย
- ถ้าแก้โค้ดใน Apps Script ภายหลัง ต้อง Deploy → **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** ลิงก์เดิมจึงจะใช้โค้ดใหม่
